Build a simple, mobile-first dairy herd management Progressive Web App (PWA) designed primarily for small 30–100 cow dairy farms.

The application should be deliberately simpler than DairyComp, DART, BoviSync, or other full herd-management programs. The primary goal is to give a farmer a very easy way to track cows, breeding, pregnancy checks, fresh cows, treatments, semen inventory, calving dates, and basic herd metrics.

MOST IMPORTANT TECHNICAL REQUIREMENT — OFFLINE FIRST

This application must work fully offline after it has been installed or loaded on the user's device.

Build it as an installable Progressive Web App (PWA).

The farmer must be able to:

Open the app with no internet connection.
View all herd records offline.
Add and edit animals offline.
Record breedings offline.
Record calvings offline.
Record pregnancy checks offline.
Record treatments offline.
View semen inventory offline.
Use the herd checklist offline.
View herd statistics such as average Days in Milk offline.

Use a local on-device database such as IndexedDB for primary application data.

Do NOT require a constant connection to a remote server for normal operation.

Design the application's data layer so cloud backup and synchronization can be added later without rebuilding the application.

If synchronization is eventually added, the local device database should remain the primary working database and synchronize with the cloud whenever an internet connection becomes available.

Add proper PWA configuration including:

Web app manifest
Service worker
Offline caching
Installable home-screen icon
Cached application shell
Offline database
Graceful handling of loss of internet connection

The application should feel like a native mobile application when installed on an iPhone, iPad, Android phone, or tablet.

HERD METRICS

Keep metrics simple.

Display:

Average Days Open

IMPORTANT DESIGN PHILOSOPHY

Do not turn this into complicated herd-management software.

A farmer should be able to learn the basic app without reading instructions.

Recording a breeding should take approximately 3–4 taps.

Recording a pregnancy result from the herd-check list should take approximately 1–2 taps.

Recording a calving should take approximately 3–4 taps.

Prioritize reliability and simplicity over advanced features.

Build the first working version around this loop:

CALVED → FRESH CHECK → BRED → PREG CHECK → PREGNANT → DRY OFF → CALVED

The application should automatically generate the farmer's work lists from those events.

BEFORE CONSIDERING THE PROJECT COMPLETE

Test these specific scenarios:

Install the app as a PWA.
Load the application while online.
Disconnect the device from internet access.
Close and reopen the application.
Confirm all herd records remain accessible.
Add a new cow while completely offline.
Record a breeding while completely offline.
Confirm semen inventory decreases offline.
Record a treatment while offline.
Close and reopen the application while still offline.
Confirm all newly entered data remains saved.
Confirm the herd checklist calculates correctly while offline.
Restore internet access and confirm no records are lost.

Do not consider "the page loads offline" sufficient.

The DATABASE AND ALL CORE FARM FUNCTIONS must actually operate offline.
